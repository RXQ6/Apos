# 术语表

| 术语 | 含义 |
|---|---|
| SPU | 标准化产品单元，一类商品的抽象 |
| SKU | 库存单元，可售卖的规格组合 |
| 预占（preoccupy） | 下单未支付前锁定库存，超时释放 |
| 扣减（deduct） | 支付成功后真正减库存 |
| 关单 | 未支付订单超时后关闭，释放预占 |
| 仅退款 | 不退货，直接退款的售后类型 |
| 退货退款 | 退回商品后再退款 |
| 主链路 | 浏览→下单→支付→履约 的核心路径 |
| 旁路 | 未登记在 ROUTING.md 的非法调用路径 |
| 场景卡 | `features/<id>/` 下的 feature.json + SCENARIO.md |
