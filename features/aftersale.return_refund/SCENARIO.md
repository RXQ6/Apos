# SCENARIO — aftersale.return_refund

> 业务拍板（2026-09-11）：**仓收货成功后**才 `payment.refund` 与库存回补。

## 前置

- 订单已发货或已完成
- 售后窗口内且无互斥售后单

## 正常步骤

1. `aftersale.open`（type=return_refund）
2. 审核通过，用户寄回（逆向物流单号）
3. 仓收货事件（质检可选通过）
4. `inventory` 回补（幂等）
5. `payment.refund`
6. 售后 `closed`，订单进入已退款完结

## 异常

| 条件 | 处理 |
|---|---|
| 未收货先退款 | **禁止** |
| 质检失败 | 拒收/二次协商，不退款或部分（另策略） |
| 回库成功退款失败 | 告警重试，不重复回库 |

## 后置

- 库存增加；退款单可对账
